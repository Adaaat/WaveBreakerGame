# WaveBreakerGame
A small 2D game created with flutter and flame for Windows and mobile.
# WaveBreakerGame

A Flutter game 

## Prerequisites

- Flutter SDK
- For Windows desktop builds: Visual Studio with "Desktop development with C++"

## Quick Start

1. Install dependencies:
   ```bash
   flutter pub get
   ```

2. Run the app:
   ```bash
   # Windows Desktop
   flutter run -d windows

   # Mobile / Default device
   flutter run
   ```

3. Build executable:
   ```bash
   flutter build windows
   ```

## Key Packages
- `audioplayers`: Audio execution and sound effects
